# 🏛️ Братство Уваги — No TikTok / No Reels Challenge Telegram Bot

**«Братство Уваги»** — це атмосферний, сучасний Telegram-бот на Python, розроблений для групового челенджу із цифрового детоксу. Бот допомагає друзям разом боротися із залежністю від нескінченного скролінгу коротких відео (TikTok, Instagram Reels, YouTube Shorts), відстежуючи щоденний прогрес, ведучи серії чистих днів (стріки), нараховуючи досвід (XP) та відкриваючи унікальні досягнення (ачивки).

Дизайн бота виконаний у мінімалістичному стилі **dark academia / digital detox**, що мотивує учасників цінувати свій час та увагу як найдорожчий ресурс.

---

## 🌟 Основний функціонал

1. **Реєстрація учасників**: Зберігає профілі користувачів із датою приєднання, поточними та найкращими стріками, досвідом (XP), рівнем та доступними заморозками стріку.
2. **Щоденне опитування**: Автоматично о **21:00** надсилає в групові чати та особисті повідомлення інтерактивне опитування: *«Чи заходив ти сьогодні в TikTok / Reels?»*.
3. **Логіка стріків**: За чистий день стрік збільшується на `+1`. Зрив повністю скидає стрік до `0` та додає `+1` до лічильника зривів.
4. **Рівні та Гейміфікація**:
   - `+10 XP` за кожен чистий день.
   - Бонуси за досягнення ювілейних стріків (3, 7, 14, 30, 50, 100 днів).
   - Ранги:
     1. 🌱 `Mind Beginner` (0 - 99 XP)
     2. 🛡️ `Focus Keeper` (100 - 299 XP)
     3. 👁️ `Attention Guardian` (300 - 599 XP)
     4. ⚡ `Dopamine Master` (600 - 999 XP)
     5. 🔥 `Scroll Destroyer` (1000+ XP)
5. **Заморозка стріку (`/freeze`)**: Кожен гравець починає з 1 заморозкою. Вона дає змогу зберегти стрік від згорання в один із критичних днів (стрік не скидається і не росте). Додаткові заморозки видаються за здобуття нових рівнів.
6. **Система ачивок (Achievements)**: Автоматичне розблокування унікальних медалей (наприклад: *«Свідомий Вікенд 🕊️»*, *«Дофаміновий Перезапуск ⚡»*, *«Урок, а не поразка 🍂»*).
7. **Інтерактивний Leaderboard**: Команда `/leaderboard` показує топ учасників чату з миттєвим перемиканням режимів сортування за допомогою inline кнопок: за найкращим стріком, за поточним стріком або за XP.
8. **Особиста статистика (`/stats`)**: Детальна картка прогресу, відсоток успіху та розблоковані медалі.
9. **Цитати та Інсайти**: Бот надсилає факти про дофамінові пастки алгоритмів або глибокі філософські цитати про увагу після кожного успішного звіту (із шансом 40%).
10. **Адмін-інструменти**: Можливість примусово запустити щоденне опитування (`/forcecheck`), скинути статистику читерів (`/resetuser`) або надіслати важливе оголошення всім гравцям (`/broadcast`).

## 🛠️ Технологічний стек

- **Мова**: Python 3.12+ (повністю асинхронний код, типізація)
- **Фреймворк**: [aiogram 3](https://docs.aiogram.dev/) (Telegram Bot API)
- **База даних**: SQLite (локально, без додаткових сервісів)
- **ORM**: [SQLAlchemy 2.0](https://www.sqlalchemy.org/) + [aiosqlite](https://github.com/nbraha/aiosqlite) (асинхронний драйвер)
- **Планувальник**: [APScheduler 3](https://apscheduler.readthedocs.io/) (для щоденних задач о 21:00)
- **Конфігурація**: `python-dotenv` (ENV змінні)
- **Контейнеризація**: Docker, Docker Compose

## 🚀 Швидкий старт (Локально)

### 1. Клонування та встановлення залежностей

Переконайся, що в тебе встановлено Python 3.12 або 3.13.

```bash
# Перейди в папку проєкту
cd d:/byetiktok

# Створи віртуальне середовище
python -m venv venv

# Активуй його
# На Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# На Linux / macOS:
source venv/bin/activate

# Встанови необхідні залежності
pip install -r requirements.txt
```

### 2. Конфігурація середовища

Створи файл `.env` на основі шаблону:

```bash
copy .env.example .env
```

Відкрий `.env` та вкажи свої налаштування:
- `BOT_TOKEN`: Отримай у [@BotFather](https://t.me/BotFather) в Telegram.
- `ADMIN_IDS`: Твій цифровий Telegram ID (можна отримати через [@userinfobot](https://t.me/userinfobot)), щоб отримати доступ до адмін-команд.
- `POLL_TIME`: Час щоденного опитування (за замовчуванням `21:00`).

Приклад `.env`:
```ini
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
ADMIN_IDS=987654321
DATABASE_URL=sqlite+aiosqlite:///byetiktok.db
POLL_TIME=21:00
```

### 3. Наповнення бази тестовими даними (Опціонально)

Щоб відразу перевірити, як виглядає лідерборд, рівні та досягнення без тривалого очікування, запусти скрипт генерації тестових даних. Він автоматично створить базу даних `byetiktok.db` та додасть трьох відомих філософів-стоїків із різними стріками та ачивками:

```bash
python seed_data.py
```

### 4. Запуск бота

Тепер ти можеш запустити бота:

```bash
python main.py
```

## 📜 Список команд бота

### Користувацькі команди:
- `/start` — Почати детокс, зареєструватися в системі та отримати 1 безкоштовну заморозку.
- `/help` — Відкрити інструкцію, маніфест Братства та опис рівнів.
- `/stats` — Показати твою особисту статистику: стріки, XP, відсоток успіху та отримані медалі.
- `/leaderboard` — Показати топ-10 учасників чату з можливістю інтерактивного сортування за стріками або XP.
- `/freeze` — Заморозити твій стрік на сьогодні (якщо спокуса занадто велика). Стрік не збільшується, але й не згорає.

### Команди адміністратора:
- `/broadcast <текст>` — Надіслати важливе повідомлення від імені бота всім зареєстрованим користувачам.
- `/forcecheck` — Негайно запустити вечірнє опитування у всіх зареєстрованих групових чатах та приватних повідомленнях користувачів (ідеально для тестування).
- `/resetuser <ID або @username>` — Повністю очистити статистику, логи, стріки та досягнення гравця (корисно проти накруток читерів).

## 🔒 Захист від накрутки (Anti-cheat)
- **Одноразовий звіт**: Бот не дозволяє відправляти більше одного звіту на день. При спробі змінити голос вилітає попередження.
- **Блокування після зриву**: Заморозку можна використати лише **до** або **замість** надсилання звіту. Не можна натиснути «Зірвався», а потім спробувати заморозити день.
- **Унікальний ID**: Всі стріки прив'язані до реальних Telegram ID з унікальними датами в базі даних.
